# Lesuto Chrome Toolkit

This plugin is store work only. It cannot read Lesuto staff CRM, leads, or outreach.

When the merchant asks you to download the Chrome companion for SDK Studio:

1. Fetch the production zip from `https://cdn.lesuto.com/chrome-toolkit/lesuto-chameleon-toolkit.zip`.
2. Unzip it on their machine.
3. Chrome → Extensions → Load unpacked → that unzipped folder.
4. Open a normal `https://` page (not `chrome://`), then **Open Studio**.

Do not use staging URLs. Do not unpack this on a shopper Hub login. The zip is the public merchant companion. Login, drafts, and publish stay in Studio.
